ABSTRACT

LuxeCart E-Commerce Website is a full-stack shopping platform designed to serve both customer users and store administrators through a single integrated application. The customer side of the system allows product browsing, category filtering, search, cart management, wishlist handling, address entry, checkout, order history viewing, account management, and support ticket submission. The administrator side provides product control, section management, support monitoring, user tracking, order review, and sales overview.

The project is implemented using Angular and TypeScript for the frontend, Bootstrap for responsive user interface design, Node.js with Express for backend services, and MySQL for relational data storage. The application is organized into reusable frontend components and backend API modules so that catalog, account, order, and support workflows remain maintainable and scalable.

This project demonstrates the practical use of modern web technologies in building a real commerce workflow that supports browsing, ordering, storage, validation, reporting, and administration in a structured way. It also provides a strong base for future extensions such as live payment gateway integration, delivery tracking, invoice generation, and production deployment.

1. INTRODUCTION

1.1 Overview of the System

LuxeCart is a web-based e-commerce system developed to provide a rich shopping experience for customers and a structured administration panel for store management. The application supports browsing products by category, searching the catalog, viewing product cards, placing orders, reviewing order history, and raising support tickets.

On the administration side, the project provides a separate admin login flow and multiple admin pages for dashboard monitoring, products, orders, store sections, support box, users, account handling, and stock visibility. This makes the project suitable for demonstration as a complete academic full-stack software system.

1.2 Specific Objectives

  • To build a full-stack e-commerce website using Angular, Express.js, and MySQL.
  • To provide customer sign-up, sign-in, password recovery, and account management.
  • To implement product search, category browsing, saved items, and cart handling.
  • To create a checkout module with delivery details and card-payment validation.
  • To store orders, order items, customer accounts, support tickets, and card summaries in MySQL.
  • To build a separate admin login and multi-page admin control center.
  • To create a responsive UI suitable for desktop browsing and project demonstration.

2. SYSTEM STUDY AND ANALYSIS

2.1 Existing System

Many basic online shopping systems provide limited product browsing and weak integration between shopping, order tracking, and administration. Older systems frequently use static listings, basic forms, and manual record handling. Support requests and user account tracking are often managed separately, making the workflow inefficient.

Common drawbacks in existing systems are:

  • Limited category filtering and weak catalog discovery.
  • No proper admin workspace for products, orders, users, and support.
  • Poor checkout validation and weak order-history visibility.
  • Lack of customer-account and support-ticket storage in a connected system.
  • Weak visual design and limited responsiveness.

2.2 Proposed System

The proposed LuxeCart E-Commerce Website provides a modern shopping portal together with a complete admin workspace. Customers can search products, view categories, manage carts, place orders, see previous purchases, and submit support tickets. Administrators can log in separately and manage products, sections, users, support requests, order visibility, and performance-related summaries.

Main advantages of the proposed system:

  • Integrated customer and admin workflows in one project.
  • Multiple store sections and category-focused product display.
  • Checkout with cash-on-delivery and card-payment support.
  • Masked card detail storage for order reference.
  • Support-ticket and customer-account persistence in the database.
  • Admin pages for dashboard, products, orders, users, stock, and support box.
  • Responsive frontend and meaningful toast feedback.

3.3 Software Profile

The project uses a layered architecture. The Angular frontend handles all visual presentation and user interactions. The Express backend provides API endpoints for products, orders, accounts, support, and admin operations. MySQL acts as the persistent relational storage layer.

The frontend contains pages for home, checkout, account, support, orders, sign-in, sign-up, product views, and separate admin pages. The backend contains database setup, seed logic, route processing, validation, and response handling. Together, these modules deliver a working commerce platform suitable for academic submission and demonstration.

4. SYSTEM DESIGN

4.1 Data Flow Diagram

The data flow of the system begins when a customer or administrator interacts with the frontend. Requests are passed to the backend API, validated, and then stored in or retrieved from the MySQL database. The processed response is returned to the frontend for visual display.

  1. Customer/Admin enters details through the frontend interface.
  2. Frontend sends request to backend API.
  3. Backend validates and processes the request.
  4. MySQL stores or returns the related data.
  5. Frontend displays the final result to the user.

4.3 Database Design

Table Name Purpose Important Fields
store_sections Stores store section names and order of display. id, name, sort_order, created_at
products Stores product catalog information. id, name, category, description, image_url, price, stock, rating
orders Stores customer order summary and delivery details. id, order_reference, customer_name, email, payment_method, total_amount, status
order_items Stores item-level details for each order. id, order_id, product_id, product_name, quantity, unit_price
support_tickets Stores customer support requests and replies. id, customer_name, email, issue_type, subject, status, admin_response
admin_accounts Stores admin credentials and role details. id, name, email, phone, password_hash, role
customer_accounts Stores customer sign-up and login data. id, name, email, phone, password_hash, password_hint
card_details Stores safe masked card-summary details for card payments. id, account_email, cardholder_name, card_last4, expiry, card_brand

5. IMPLEMENTATION

Implementation is the stage where the system design is converted into a working application. The LuxeCart project is implemented using Angular in the frontend and Express.js in the backend. MySQL is used as the storage engine for sections, products, orders, support tickets, accounts, and masked card summaries.

5.1 Customer Module

The customer module contains pages for browsing products, filtering by category, searching products, adding items to cart, saving items, viewing account details, placing orders, reviewing previous orders, and submitting support requests.

5.2 Checkout Module

The checkout module validates name, phone, address, city, state, postal code, payment method, and card details before placing the order. Card-based orders store only masked card detail information for safe record keeping.

5.3 Admin Module

The admin module contains a separate admin login page and multiple control pages such as dashboard, products, orders, accounts, users, out-of-stock, and support box. It is designed to help the store administrator manage daily operations from one control center.

5.4 Database and Seed Module

Database tables are created and updated from the backend. Seed logic is used to populate section and product data for demonstration. The project also supports product image updates, INR price display, toast feedback, and data refresh flows.
